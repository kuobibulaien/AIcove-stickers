# AIcove-stickers

AIcove 可选下载的动图表情包。在 AIcove「表情包」设置页的「可选下载」里一键下载导入，也可以从 [Release v1](https://github.com/kuobibulaien/AIcove-stickers/releases/tag/v1) 手动下载 ZIP 后导入。每个套组文件夹附 `labels.json`，记录套组名、原作者和每张图的标签。
